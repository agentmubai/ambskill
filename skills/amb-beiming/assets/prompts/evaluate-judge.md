## 五维（每维 0–5，整数或 .5）

1. **方法选择**：识别了本题关键条件并选对路。反转题看条件变了路有没有换；近邻题看有没有正确交接（说明该找谁、带什么去）而不是硬答；路由器题看归对没归对。0 = 答非所问；3 = 路对但没说清为什么；5 = 条件、路、理由都对。
2. **成品可用**：交出的是提问者能直接用的东西。0 = 只有"建议你考虑"；3 = 有成品但要大改；5 = 拿走就能用，缺的地方用槽位或追问标清。
3. **原法忠实**：用的判断与句式是不是上面摘要那套方法。对照摘要：回答有没有按摘要里的模块判断、分支条件是不是那个模块的。只有通用商业常识 ≤ 2；点名了模块但用法不对 3；判断与分支都对得上 5。
4. **材料贴合**：提问者给的事实有没有真用上；没给的有没有编。0 = 无视材料或编了关键事实；编了数字、编了行业事实直接 ≤ 2；3 = 用了材料但有一两处泛泛套话；5 = 每个判断都落在提问者给的事实上，缺的用槽位或追问标出。
5. **自检返工**：有没有说清哪些待补、哪里可能不对、下一步怎么改。0 = 没有任何自检；3 = 有"以上仅供参考"式的空话；5 = 逐项列出待补事实、不确定的判断与下一步动作。

每维给一句话理由，理由里引用回答的具体句子作证据。
