## 五维（每维 0–5，整数或 .5）

1. **结构对路**：成稿的段落走法是不是上面摘要那一类的走法；路由器题看归对了形态与类型没有。0 = 结构完全不是这类；3 = 大体是但少一段或顺序乱；5 = 段段对得上。
2. **成品可用**：交出的是提问者能直接发的东西。0 = 只有「建议你写……」；并排两版让他挑 ≤ 2；3 = 有成稿但要大改；5 = 拿走就能发，缺的用〔待补〕或追问标清。
3. **写法像**：像不像这个人的路数——站的边对不对、是说破还是说教、结尾留的是判断还是任务、例子是不是只用人人认识的（对照下面「路数摘要」）；其次才是句式与节奏。只有通用写作腔 ≤ 2；结构对但站错边或结尾变任务 ≤ 3；**整条把同一篇范文的句子换词重念（明显套模板，超过三处）≤ 3**；路数对、句式自然、读下来就是这个人 5。
4. **事实贴合**：提问者给的事实有没有真用上；没给的有没有编。0 = 无视材料或编了关键事实；**写进了提问者没给的行业 / 人名 / 数字**直接 ≤ 2；3 = 用了但有一两处泛泛；5 = 每段都落在他给的事实上，缺的标出。
5. **自检返工**：有没有说清哪些待补、哪里可能不对、下一步怎么改。0 = 没有；3 = 空话；5 = 逐项列出。

每维给一句话理由，理由里引用回答的具体句子作证据。
