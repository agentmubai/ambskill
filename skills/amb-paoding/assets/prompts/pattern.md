## 你要做的不是拆结构，是把这个人蒸出来

读完这些作品，要能回答：**如果他现在站在这儿，替使用者写这一类的一条，他会怎么看这件事、每一段要达成什么、凭什么能达成、读起来什么劲儿；读者为什么会停下来、为什么看他的、看完为什么被种草。** 结构只是明面；暗地里的目的、他凭什么做得到、读者凭什么买账，才是使用者能借的东西。为拆而拆的写法书没有用。

## 料

${listing}

每篇从头读到尾。读一篇先标它的开头 / 中间 / 结尾在哪儿断、每一小段第一句是什么，再读下一篇。全读完再看：哪些选择每篇都在——那才是他的，只出现一次的是那篇的。

## 写 `${pattern_out}`

## 他是怎么看事的（魂）
每条写成「他会……而不是……」的选择句，每条 ≥ 2 个不同原件的证据（编号）。≥ 3 条。写不出就少写，别用形容词凑。
- **<选择>。** <一两句说明>。证据：「<原话>」（o.._..）；<另一篇怎么体现>（o.._..）
- …
- **禁区（这些篇里从不出现）：** <他从不做的事>
写之前先答三句：如果是他看这件事，他会先注意什么？他替谁说话？他想让读者带走哪一句？

## 读者账：他为什么会看、为什么会被种草
站在读者那边答五问，每问一两句 + 证据（编号）+ 落在哪个小段。这是暗线的另一面：作者要达成什么，得靠读者愿意。
- **他为什么会停下来：** <开头凭什么让人不划走>（o.._..；第 1 小段）
- **我能帮他什么：** <这一类给读者的到底是什么——一个说法、一个动作、一次被说中>（o.._..；第 N 小段）
- **他为什么要看这个：** <他此刻的处境 / 情绪，为什么这件事跟他有关>（o.._..）
- **他为什么看我的，不看别人的：** <作者凭什么——身份、立场、看事的角度>（o.._..；第 2 小段）
- **看完为什么会被种草：** <读完他信了什么、想要什么、会做什么；哪一段完成的>（o.._..；第 N 小段）

## 开头

- 明：这段明面上写了什么、怎么写的
- 暗：这段真正要达成什么——为什么放这儿、放量还是收口、让人点头还是翻转

- 三大段固定是 开头 / 中间 / 结尾；小段按料来，编号全书连续（1、2、3…），每大段至少一个小段，**中间至少两个**——三大段只定位置，功能在小段，不许一个「中间」包七成篇幅。
- 有的小段会在一篇里转好几轮（公域直播的 讲品 → 互动 → 催单，一场转三四遍）。这是**结构循环**：同一个小段的走法重复出现，每轮装的内容不同——讲品一轮换一个品，催单一轮换一个理由；不是找内容一样的段落。这种小段加一行 `- 可循环：<哪几篇转了几轮、每轮换的是什么>（o.._..；o.._..）`，至少两篇范文有证据才准标。**循环是从料里看出来的，不是形态给的**：私域直播可能没有，课程多半没有，别因为是直播就标。
- 「例」是原文**整段**，不是摘一句：把范文那一段从头到尾抄进引用块，末尾标编号。原文里的说话人行、时间戳跳过不抄。
- 「术」是可套的句子，逐字 + 哪几个字换；人名、数字、行业、地名是事实不是句式。某小段真没有可套句式就写「候选无」，并在「例」里说明为什么。
- 「凭什么」不是夸他：是他有什么让这段成立——年限、积累、立场、手里的事实。写清了，「你要有什么才能借」才写得出来。

## 写 `${report_out}`

小段数与段名；魂几条、哪条证据最弱；读者账五问里哪一问最难从料里答；哪篇没被任何小段的「例」引到及原因；你觉得这类最容易和哪个相邻类型混；你拿不准的判断。

## 硬要求

- 「原话」（编号）与每个「例」块必须是所标原件正文的逐字子串；标错编号也算错。脚本逐字核，不过不进下一步。
- **「」只包原话，编号紧跟在它后面**（40 字内）。你自己的话不要用「」包——脚本会把它当引文去核，也会把它配给最近的编号。
- 魂每条 ≥ 2 篇证据；一条证据都没有的是形容词，不许写。读者账五问都要答，答案落到 ≥ 3 个原件。
- 不评价好坏，不加建议，不用行业套话（「要有钩子」）替代对他选择的描述。
- 不写过程用语。写完只回复一句：文件路径、小段数、魂条数。
