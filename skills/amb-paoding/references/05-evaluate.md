# 05 轻验收：对裸模型盲评一套题

## 目标与产出

回答一个问题：装了这套技能，比不装强多少、弱在哪一件。不设通过线；把差距和扣分件摊出来给使用者看。

产出：`work/tests/<题集>/{questions.md, answers/<来源>/<键>.md, packets/, key.json, scores/<键>-J<n>.md, scores.json, report.md}`。完成 = 矩阵完整（tally ok）+ report 在。

## 动作

1. `paoding.py evaluate questions --testset 常备` → 派一个子代理出题（不读技能，题里的行业全新造）。每类型 2 题（带事实 / 缺事实），路由器 2 题（明确 / 模糊）。
2. `paoding.py evaluate answers --sources bare,new` → 每个 (来源, 类型) 一份答题提示词；同一轮全部用同一个答题模型。
3. `paoding.py evaluate judge` → 打乱成甲乙，两位评委各一份提示词。评委只看结构摘要（小段名），不看魂、句式与例。
4. `paoding.py evaluate tally`：任务 × 题 × 来源 × 两评委缺一格即拒。
5. `paoding.py evaluate report` → `report.md`。
6. 写一段给使用者的验收说明（模板见下），放 `work/docs/`。

## 规则

- 出题人不读技能、写法书、原件；题里不出现类型名、句式、来源人名；行业与事实全部新造，否则测不出"事实不搬"。
- 五维：结构对路 / 成品可用 / 写法像 / 事实贴合 / 自检返工，各 0–5。评委锚点在 `assets/prompts/evaluate-judge.md`。「写法像」看的是像不像这个人的路数（站边、说破还是说教、结尾留判断还是任务），不只是句式；整条把同一篇范文的句子换词重念（超过三处）≤ 3。评委拿到的是结构与路数摘要（魂条去掉原话与编号），看不到范文。
- 扣分件只能填 骨架 / 句式 / 样例 / 事实 / 无。
- 差距 < 1 分不解读；≤ −1 标"低于裸模型"并列扣分件。不判 PASS / WEAK / FAIL。
- 矩阵必须完整；缺格不许用均分掩盖。
- 轻验收不是门：deliver 看到没有报告只提醒。但要在成品 README 写明"未对裸模型盲评"。

## 依据

外层：对照才有意义——没有裸模型对照，"像不像"只是感觉。

内层（可观察）：
1. `scores.json.complete = true`。
2. report.md 每类型一行差距与读法。

为什么这样定：
- 不设硬门：这套技能的价值在"能不能发"，评委是模型，硬门会把人的判断挡在外面；差距报告给人看，人定。
- 评委不看句式原话：否则会按"像不像原文"打分，而不是按"这一类的结构与成品能不能用"。
- 行业新造：句式表里带着来源人的行业，题若重合，事实不搬就测不出来。

## 模板

`work/docs/验收说明.md`（对使用者写）：

```
# 验收说明：<箱名>

## 一句话
<N> 个类型里 <n> 个高于不用它、<m> 个差距在噪声内、<k> 个低于。满分 25。

## 每个类型
| 类型 | 不用它 | 用它 | 差距 | 读法 | 弱在哪一件 |

## 你确认过的事
- 类型（<日期>）：<他的原话>

## 题从哪来
每类型两题：一题给足事实、一题只给方向；路由器两题。出题人不读技能，题里的行业全部新造。两位评委盲评。

## 提醒
生成与评审都是模型；能不能发要你用过才知道。低于不用它的类型，多半是句式太少或事实搬了，下一轮增量先看它。
```

## 常见失误

- 出题人看了类型卡里的原话：题的行业和样例重合，事实贴合虚高。
- 同一轮换答题模型：分数不可比。
- 缺格用均分补：tally 会拒，不要绕。
- 把轻验收当门去卡交付：它是给人看的；要不要带着"低于裸模型"的类型交付，使用者定。
